Discovery is not trust; review/ON prove no readiness. Payload/state paths: §1. Execution resolves one canonical directory through the full loader per request. Conflict checks use fresh manifest/enablement peers (`skill_peer_inventory.py`), never hashed payloads or partial objects. Its provenance survives OFF, preserving later intentional ON, not execution authority. One duck-typed verdict (`skill_conflicts.py`) keeps loaded and peer answers aligned. Both refresh after slow lifecycle work: cross-process disable, revoke or restored-mtime edits apply next request; valid manifests keep conflicts even with unreadable payloads.

### Extension import and isolation

`extension_import_staging.py` shares complete `__extension_imports/` trees by content and runtime/dependency identity. PID references survive until actual teardown. The cross-process imports lock lives beside disposable skill state, so deletion cannot replace its inode. Local delete removes payload and records the existing uninstall tombstone; live PID references defer state cleanup. Any same-name install, across sources, preserves shared state/grants. Cleanup errors retain the tombstone for normal sweep/release retry; completed import retirement does not strand reload admission.

Review/grants bind to code. Per-call children reuse the loader with scrubbed env and proxy tools/routes/WS/UI/settings/companion descriptors; persistent subscriptions/tasks need in-process or companion lifecycle. The capability matrix owns support, not platform names. `extension_catalog.json` caches success only for exhaustive `catalog_inputs`, hashing runtime, host revision, grants and declared settings/env, never storing values. Other dependencies retain the catalog child; bundled payloads never opt in implicitly. Namespacing, permissions, per-skill tracking and atomic unload bind the powerful in-process path.

`skill_repair_admission.py` admits ordinary managed repair against exact bytes (§6). Bucket/name still produces `skill_repair`, normalized to `normal` at promotion: a payload selector, not a reduced tool profile. Installed payloads need no Git copy; repair review never forces unload.

### Live Conversation and provider packages

PluginAPI 2.1's in-process `register_live_conversation` and `register_realtime_provider(..., session=...)` separate the feature (`skills/live_conversation/`: media/tools, Talk A) from `gemini_live`, `grok_realtime`, `openai_realtime` (wire, captions, usage, renewal). Context, tool policy/executor/checkpoints, history, mailbox, model-wait Stop and attempt ledger keep their owners. `call_peers.py` carries provider audio directly; `call_protocol.py` preserves companion framing. Presence retains its ceiling, gate, registry and provenance: external audio cannot confer owner authority. Browser capture uses shared leases (§3).

The host seals connections before dispatch. `pricing_catalog.py` retains exact LiteLLM tariffs and their digest/date; `live_usage.py` reserves and settles each response through `usage_accounting.py`. `_usage_settlement.py` keeps unpriced modalities unknown and never reprices a retained quote. OpenAI encodes the unchanged allowance as 1–4096 or `"inf"`; the latter needs fresh exact-route `response_limits` evidence for its model maximum. The physical request carries a known native bound even above the allowance. Unknown bounds (including Grok's absent limiter) remain `None`, with the ordinary allowance only an estimate. Receipts separate ordinary fit, allowance, evidence and reserve. Missing modality prices retain exposure; neither text prices nor text-density learning substitute for mixed usage. Gemini renews at a completed turn with full role history in system layout; host remeasures common context. Socket loss ends the call; no paid retry. Unload removes dispatch and requests Stop; imports outlive tool/history/socket teardown, then requeue reconcile.

`realtime_turn.py` separately previews whole input offline and funds one digest via `realtime_execute`. Its probe bound governs fit; required pointers need a reader. `realtime_setup.py` retains imports through close. Neither intent restores authority on recovery/Continue; Pause has no resumable checkpoint, Stop ends execution. Client shapes: `CLIENT_CONTRACT.md`.
